# AURA
Add your Aura-points using our AURA!! 📈  Meet Aura (Audio Visual Response) built with Arduinos, a bunch of jumper wires and way too much caffeine.  Aura listens to your voice, displays both the input and output on an LCD, and even talks back through a speaker. Basically, she’s Alexa’s budget-friendly cousin with some serious personality.
